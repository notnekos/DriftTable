# DriftTable

Бесконечный рабочий стол для Windows в духе [DriftWM](https://github.com/malbiruk/driftwm):
обои и окна остаются как есть, а **рабочий стол становится холстом**, который можно таскать
средней кнопкой мыши, прокручивать и масштабировать. На нём лежат файлы, картинки,
заметки и рисунки, и места хватает на всё.

- **Обои не трогаются.** Холст полупрозрачный и встраивается туда же, где живут значки
  рабочего стола, *поверх* обоев. Поэтому Lively Wallpaper, Wallpaper Engine и обычные
  обои продолжают работать.
- **Окна ведут себя как обычно.** Холст лежит под всеми окнами, переживает `Win+D` и
  не появляется на панели задач.
- **Файлы настоящие.** Холст показывает содержимое папки «Рабочий стол»: новый файл
  сразу появляется на холсте, удалённый пропадает. Открытие, контекстное меню Explorer,
  переименование, удаление в корзину и перетаскивание в другие окна работают как на
  обычном рабочем столе.

## Управление

| Действие | Как |
|---|---|
| Двигать холст | зажать **среднюю кнопку** и тянуть (если отпустить на ходу, холст ещё немного проплывёт по инерции), или `Пробел` + левая кнопка |
| Прокрутка | колесо: вертикально; `Shift` + колесо или наклон колеса/тачпад: горизонтально |
| Масштаб | `Ctrl` + колесо, щипок на тачпаде, `+` / `-`, `Ctrl+0` = 100% |
| Вернуться к началу / показать всё | `Home` / `F` |
| Выделить, двигать | левая кнопка; рамкой по пустому месту; `Ctrl`/`Shift` добавляют к выделению |
| Открыть | двойной щелчок или `Enter` |
| Меню | правая кнопка: на файле родное меню Explorer, на пустом месте меню холста |
| Переименовать | `F2` |
| Удалить | `Del`: файлы уходят в корзину, заметки, картинки и рисунки удаляются (отменяется через `Ctrl+Z`) |
| Отменить / вернуть | `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`) |
| Перо / ластик / выделение | `B` / `E` / `V` или `Esc`. Цвета `1`–`8`, толщина `[` и `]`. Панель инструментов появляется сверху |
| Заметка | двойной щелчок по пустому месту или `N`. `Ctrl+Enter` или `Esc` завершают ввод |
| Вставить | `Ctrl+V`: файлы копируются на рабочий стол, картинка из буфера (скриншот) прикрепляется, текст становится заметкой |
| Копировать файлы | `Ctrl+C`, потом их можно вставить в Explorer |
| Изменить размер | потянуть за уголок выделенной картинки или заметки |

### Перетаскивание

- **Файлы на холст** (из Explorer, браузера и т. д.) перемещаются в папку «Рабочий стол»,
  как при перетаскивании на обычный рабочий стол: с того же диска перемещаются, с другого
  копируются. `Ctrl` всегда копирует, `Shift` всегда перемещает.
- **Картинки с зажатым `Alt`** прикрепляются к холсту как изображения. Копия хранится в
  данных программы, а файл на рабочий стол не попадает. То же делает пункт «Прикрепить
  как картинку» в меню файла-изображения.
- **Файлы с холста** можно тащить прямо в окно Explorer, в браузер, в мессенджер или на
  панель задач: как только курсор уходит на другое окно, начинается обычное
  перетаскивание Windows.

## Как это устроено

Windows рисует значки рабочего стола в окне `SHELLDLL_DefView`. Его родитель — `WorkerW`
(до Windows 11 24H2) или `Progman` (24H2 и новее). Программы живых обоев рисуют в
*другом* `WorkerW`, который лежит под значками. DriftTable создаёт полупрозрачное окно
(layered child window) рядом со значками и прячет сами значки, а обои остаются видны в
каждом прозрачном пикселе. Всё рисуется через Direct2D/DirectWrite, иконки и миниатюры
берутся у оболочки (`IShellItemImageFactory`) в фоновом потоке.

Если Explorer перезапустится или программа обоев пересоздаст `WorkerW`, DriftTable
заметит это и встроится заново.

Режимы (параметр `Mode` в `settings.ini` или ключ командной строки):

- `--embed` (по умолчанию): дочернее окно у значков рабочего стола. Самая аккуратная
  интеграция.
- `--overlay`: отдельное окно внизу стопки окон, принадлежащее рабочему столу. Запасной
  вариант, если на вашей сборке Windows встраивание не показывает холст. Горячие клавиши
  в этом режиме работают только во время ввода текста: окно не забирает фокус, чтобы не
  всплывать над другими окнами.
- `--window`: обычное окно с нарисованным фоном вместо обоев, для пробы и отладки.

## Где лежат данные

`%APPDATA%\DriftTable\`:

- `canvas.txt` — холст: позиции файлов, заметки, рисунки, картинки и камера (обычный текст);
- `pictures\` — копии прикреплённых картинок;
- `settings.ini` — настройки.

Значок в трее: вернуться к началу, перо, показать или скрыть значки Windows, вернуть
«Корзину» и «Этот компьютер», автозапуск, выход. При выходе значки Windows возвращаются
на место. Если процесс завершили принудительно, значки вернутся после перезапуска
Explorer или после следующего запуска и выхода из DriftTable.

## Сборка

Нужны Windows 10/11 и CMake 3.20+.

**Visual Studio 2022 (MSVC):**

```bat
cmake -S . -B build -A x64
cmake --build build --config Release
build\Release\DriftTable.exe
```

**MinGW-w64** (в том числе кросс-компиляция из Linux):

```sh
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64.cmake -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
```

Готовый `DriftTable.exe` также собирается в GitHub Actions (артефакт `DriftTable-win64`).

## Структура

| Файл | Что внутри |
|---|---|
| `src/App.cpp` | окна, встраивание в рабочий стол, трей, настройки, главный цикл |
| `src/AppInput.cpp` | камера (панорама, инерция, плавный зум), мышь, клавиатура, меню |
| `src/AppDraw.cpp` | отрисовка холста и панели инструментов |
| `src/AppBoard.cpp` | синхронизация с папкой «Рабочий стол», drag & drop, картинки, заметки |
| `src/Board.*` | модель холста, сохранение, отмена |
| `src/DesktopHost.*` | поиск `Progman` / `WorkerW` / `SHELLDLL_DefView`, слежение за папками |
| `src/ShellOps.*` | открытие, контекстное меню Explorer, операции с файлами, OLE drag & drop |
| `src/ImageLoader.*` | иконки и миниатюры оболочки, декодирование картинок (WIC) в фоне |
| `src/Renderer.*` | Direct2D в 32-битный DIB и `UpdateLayeredWindow` |
